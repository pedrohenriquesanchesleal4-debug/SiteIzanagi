# References — Accessibility Reviewer

> Curadoria dos melhores sites/referências (2026) para auditoria e implementação de acessibilidade web (a11y). Use como fonte de padrões e inspiração.

## Docs canônicas
- [W3C WAI](https://www.w3.org/WAI/) — iniciativa de acessibilidade da W3C; fonte oficial de diretrizes.
- [WCAG 2.2](https://www.w3.org/WAI/WCAG22/) — critérios de sucesso atuais de acessibilidade web.
- [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/) — padrões de widgets acessíveis com ARIA.
- [MDN Accessibility](https://developer.mozilla.org/en-US/docs/Web/Accessibility) — referência prática de acessibilidade em HTML, CSS e ARIA.
- [web.dev Learn Accessibility](https://web.dev/learn/accessibility) — curso oficial do Google sobre a11y aplicada.

## Referências e inspiração
- [WebAIM](https://webaim.org/) — artigos, ferramentas e estatísticas de acessibilidade na web.
- [Deque axe](https://www.deque.com/axe/) — motor de testes automatizados de acessibilidade usado em CI.
- [IBM Accessibility](https://www.ibm.com/able/) — checklists e guidelines corporativos de a11y.
- [The A11y Project](https://www.a11yproject.com/) — guia comunitário pragmático de acessibilidade.
- [Inclusive Components](https://inclusive-components.design/) — padrões de componentes inclusivos com código.

## Comunidade / galerias / exemplos
- [W3C WAI Patterns](https://www.w3.org/WAI/patterns/) — exemplos e padrões de componentes acessíveis (APG).
- [MDN Web Docs](https://developer.mozilla.org/) — exemplos práticos de landmarks, roles e foco.
