# References — Mobile Engineer

> Curadoria dos melhores sites/referências (2026) para engenharia mobile full-cycle (React Native/Expo, Flutter, PWAs). Use como fonte de padrões e inspiração.

## Docs canônicas
- [React Native Docs](https://reactnative.dev/docs) — referência de componentes, arquitetura e bridging nativo.
- [Expo Docs](https://docs.expo.dev/) — EAS Build, OTA updates, push e módulos nativos.
- [Flutter Docs](https://docs.flutter.dev/) — rendering, state management e engine.
- [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) — diretrizes de plataforma iOS.
- [Material Design 3](https://m3.material.io/) — design system e tokens para Android/Flutter.

## Referências e inspiração
- [Android Developers](https://developer.android.com/) — performance, tooling e APIs de plataforma.
- [Apple Developer Documentation](https://developer.apple.com/documentation/) — frameworks e APIs nativas.
- [Mobbin](https://mobbin.com/) — benchmark de padrões de UI em apps reais.
- [web.dev](https://web.dev/) — guias oficiais de PWAs e web mobile.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos sobre engenharia mobile e performance.

## Comunidade / galerias / exemplos
- [Dribbble](https://dribbble.com/) — galeria de UI mobile para referência visual.
- [React Native Community](https://github.com/react-native-community) — libs e guias comunitários.
- [Flutter Showcase](https://flutter.dev/showcase) — apps reais em Flutter como referência de produção.
