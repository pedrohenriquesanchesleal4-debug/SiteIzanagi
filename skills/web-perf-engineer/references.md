# References — Web Performance Engineer

> Curadoria dos melhores sites/referências (2026) para auditoria e otimização de performance web (Core Web Vitals). Use como fonte de padrões e inspiração.

## Docs canônicas
- [Learn Web Vitals](https://web.dev/learn-web-vitals/) — curso oficial do Google sobre Core Web Vitals.
- [Lighthouse Docs](https://developer.chrome.com/docs/lighthouse/) — documentação de métricas, audits e scores.
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) — ferramentas de profiler, performance e network.
- [PageSpeed Insights](https://pagespeed.web.dev/) — medição de laboratório e campo com relatórios.
- [V8 Blog](https://v8.dev/) — como a engine JS executa e otimiza código (engine do Chrome/Node).

## Referências e inspiração
- [Front-End Performance Checklist](https://github.com/thedaviddias/Front-End-Performance-Checklist) — checklist completo de otimização (repo).
- [web.dev](https://web.dev/) — artigos oficiais de pattern animações, images, CSS e rendering.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos aprofundados sobre performance frontend.

## Comunidade / galerias / exemplos
- [WebPageTest](https://www.webpagetest.org/) — testes reais de velocidade em device/location real com vídeo.
- [V8 Blog](https://v8.dev/blog) — análises técnicas de engine, GC e optimizations.
