# References — QA Engineer
> Curadoria dos melhores sites/referências (2026) para revisão rigorosa de qualidade, tipagem, acessibilidade e consistência visual.

## Docs canônicas
- [TypeScript](https://www.typescriptlang.org/) — Configuração strict mode e cheatsheets de tipagem.
- [MDN Web Docs](https://developer.mozilla.org/) — Referência canônica de APIs web e HTML/CSS.
- [React](https://react.dev/) — Documentação oficial de componentes e hooks.
- [ESLint](https://eslint.org/) — Regras de lint e boas práticas de JavaScript/TypeScript.

## Checklists / práticas
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — Critérios de sucesso de acessibilidade.
- [WebAIM](https://webaim.org/) — Checklists de contraste, semântica e navegação por teclado.
- [axe](https://www.deque.com/axe/) — Testes automatizados de acessibilidade.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse/) — Auditoria de performance, acessibilidade e SEO.
- [Can I Use](https://caniuse.com/) — Validação de suporte entre navegadores.

## Comunidade / exemplos
- [Google Testing Blog](https://testing.googleblog.com/) — Práticas de testes em escala.
- [Ministry of Testing](https://www.ministryoftesting.com/) — Comunidade de QA com cursos e webinars.
