# References — Frontend Dev

> Curadoria dos melhores sites/referências (2026) para edição visual, componentes React/Next.js/TypeScript e design systems. Use como fonte de padrões e inspiração.

## Docs canônicas
- [React Docs](https://react.dev/) — documentação canônica de components, hooks e rendering.
- [Next.js Docs](https://nextjs.org/docs) — App Router, Server Components, data fetching e otimização.
- [TypeScript Docs](https://www.typescriptlang.org/docs/) — tipos, generics e boas práticas de tipagem.
- [Tailwind CSS Docs](https://tailwindcss.com/docs) — design tokens e utilities do design system.
- [MDN Web Docs](https://developer.mozilla.org/) — referência de HTML, CSS e APIs do browser.

## Referências e inspiração
- [shadcn/ui](https://ui.shadcn.com/) — componentes acessíveis e elegantes com padrão copy-paste + Radix.
- [Smashing Magazine](https://www.smashingmagazine.com/) — artigos aprofundados sobre UI engineering e CSS.
- [web.dev](https://web.dev/) — guias oficiais de rendering, layout e best practices de frontend.
- [Awwwards](https://www.awwwards.com/) — sites premiados como referência de acabamento visual.
- [Storybook](https://storybook.js.org/) — padrões de desenvolvimento de componentes isolados e testáveis.

## Comunidade / galerias / exemplos
- [Dribbble](https://dribbble.com/) — galeria de UI/UX para inspiração de componentes e páginas.
- [Frontend Mentor](https://www.frontendmentor.io/) — desafios reais para treinar implementação de layouts.
- [CodePen](https://codepen.io/) — exemplos executáveis para validar técnicas rapidamente.
